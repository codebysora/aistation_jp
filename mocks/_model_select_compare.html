Model Select 改修案 — 2 案併走

先方共有のサンプル preset.json + model_select.html を元データに、 UI を 2 案で制作。両案とも同一 preset データを描画しているので、見た目だけを比較できます。

こちら案

案A: Plan D 系統を踏襲

  • カード基調: 既存 catalog-card（白背景）
  • Modality: IN→OUT アイコン (Plan D)
  • 主指標: 横バー Int/Cod/Math (0–20)
  • 右上: CPU/GPU バッジ
  • ハイライト: TOP 指標ピル (最高スコアを目立たせ)
  • 下段: Spd / TTFT を補助情報として小さめに
  • Capabilities: tool_use / reasoning をニュートラルタグで表示
  • 詳細ページ: カードクリック → 18 列ベンチマーク + Spec + Parameters + Deploy CTA

先方案

案B: 先方サンプル準拠

  • カード基調: 既存 c-model-card（dark）
  • Modality: フラット modality タグ（IN/OUT 区別なし、output はタブで切替）
  • 主指標: 5-dot 円 2 カラム (Int/Cod/Mat ｜ Spd/TTFT)
  • 右上: CPU/GPU バッジ
  • 下段: context N tokens
  • Capabilities: tool use のみタグ表示
  • Detail view: 列の表示切替 + ソート (今回モックでは省略)

軸案A (こちら)案B (先方)
カード背景 白 (catalog-card) ダーク (c-model-card)
Modality 表示 IN→OUT アイコンの 1 行（Plan D） フラットなタグ列（input のみ）
スコア可視化 横バー (連続値) 5-dot 円 (離散 5 段階)
情報密度 中（バー + 数値 + Spd/TTFT 別段） 高（Int/Cod/Mat と Spd/TTFT が同段）
スコア精度の伝わりやすさ ○（連続値が直観的に見える） △（5 段階に丸まる、しきい値で印象が変わる）
カード間の比較しやすさ ○（バー長で並列比較可） ◎（円の塗り数が一目で揃う）
多モダリティ (T,I,A,V → T) の表現 IN/OUT が分かれて意味明瞭 output 推論はタブ依存、input は横並びで完結
既存 UI との整合 そのまま接続可（現行スタイルに最も近い） カード見た目が既存と乖離（既に c-model-card は別ページで利用）
