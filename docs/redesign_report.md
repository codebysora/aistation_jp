## 2. 改修の全体方針

### 2.1 デザインシステムの統一（`rd-*` プレフィックス導入）

**意図:** 改修前は `c-*`（component）プレフィックスのカスタムクラスが使われていたが、命名の一貫性が不十分だった。redesign では `rd-*` プレフィックスに統一し、コンポーネントの責務を明確化した。

| 改修前 | 改修後 | 用途 |
|--------|--------|------|
| `c-nav__*` | `rd-navbar` | ヘッダーナビゲーション |
| `c-side-menu` | `rd-sidebar` | サイドバー |
| `c-contents-area` | `rd-content` | メインコンテンツ領域 |
| `card p-card` | `rd-card` | カードコンポーネント |
| `c-modal` | `rd-modal` | モーダルダイアログ |
| `c-table--*` | `rd-table--*` | テーブルバリエーション |
| `c-danger-link` | `rd-link-danger` | 危険操作リンク |
| （各種ボタン） | `rd-btn-action` | アクションボタン共通 |

### 2.2 CSS カスタムプロパティによるカラーシステム

**意図:** ハードコードされた色指定（`#e9e9e9`, `#666666c7` 等）を排除し、CSS 変数で一元管理することでテーマ変更や保守性を向上させた。

```css
--rd-primary: #0F66DC;      /* メインブルー */
--rd-secondary: #2FC5FB;    /* アクセントシアン */
--rd-tertiary: #505050;     /* サイドバー等ダークグレー */
--rd-success: #77C845;      /* 成功 */
--rd-warning: #F0C987;      /* 警告 */
--rd-danger: #DA5050;       /* 危険 */
```

### 2.3 レイアウトの統一

**意図:** 全ページで共通のアプリケーションシェル（ヘッダー + サイドバー + コンテンツ）を採用し、画面遷移時のUI一貫性を確保した。

- **ヘッダー:** 高さ 56px の固定ナビバー（ロゴ、ユーザー情報、ログアウト）
- **サイドバー:** 幅 260px の固定ナビゲーション（Admin / Management セクション分離）
- **コンテンツ:** カードベースのレイアウトで統一

## 3. ページ別の主な改修内容

### 3.1 index.html（ダッシュボード）

| 項目 | 改修前 | 改修後 |
|------|--------|--------|

**意図:** インラインJSの外部ファイル化により、HTML のコード量を大幅に削減し保守性を向上。

## 4. 横断的な改修

### 4.1 JavaScript の外部ファイル化

**改修前:** 各HTMLページにインラインで `<script>` ブロックを記述
**改修後:** `static/js/app.js` に共通ロジックを集約

**app.js に含まれる機能:**
- HTMLエスケープヘルパー（XSS対策）
- クリップボードコピー機能（バルーンフィードバック付き）
- テーブルフォーマッター（APIキー、チーム、ユーザー等）
- イベントデリゲーション（モーダル操作、ナビゲーション）
- アコーディオン開閉（詳細設定）

**意図:** DRY原則に基づき、重複していたJS処理を一元化。HTML の見通しを改善。

### 4.2 CSS 設計の刷新

**改修前:** Bootstrap ユーティリティ + インラインスタイルの混在
**改修後:** `static/css/style.css`（1086行）に体系的なデザインシステムを構築

**主な構成:**
- CSS カスタムプロパティ（カラー、スペーシング、シャドウ、トランジション）
- コンポーネントスタイル（ヘッダー、サイドバー、カード、テーブル、フォーム、ボタン、バッジ、モーダル等）
- レスポンシブ対応（991.98px ブレークポイント）
- インタラクション（ホバー、フォーカス、コピーバルーン）

**意図:** デザイントークンの一元管理とコンポーネント設計により、一貫した見た目と保守性を実現。

### 4.3 アクセシビリティ改善

| 改修項目 | 詳細 |
|---------|------|
| フォームラベル | `for`/`id` 属性の整合性を確保 |
| ボタン要素 | アクション用途の `<a>` を `<button>` に変更 |
| ARIA ラベル | セマンティック HTML コメントの追加 |
| サイドバー | `active` クラスによる現在位置の明示 |

### 4.4 インラインスタイルの排除

**改修前:** `background-color: #e9e9e9`, `color: #666666c7` 等のハードコード
**改修後:** Bootstrap ユーティリティクラス（`bg-light` 等）またはCSS変数に置換
